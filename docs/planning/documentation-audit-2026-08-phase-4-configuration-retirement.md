## The generator route

`src/pages/en/self-hosting/configuration-generator.astro` was not deleted. It
was reduced from the full tool page (blob `2c73327b9df7987188f9ba3d0960daefc05eaa5d` at the merge-base) to a
forwarder, because Astro's static redirect stubs cannot carry
a query string or a fragment and the generator stores its selections in the
query string. Read the retired page with:

```sh
git show 1bbed3c6655221d05bfd8a28b0b31a4544cd132e:src/pages/en/self-hosting/configuration-generator.astro
```

Its prose moved to `src/content/docs/en/reference/generator.mdoc`. The
`configGeneratorRedirects` fan-out was removed in the same change that added
the `movedPages` rows, so no source URL is both a page and a redirect:
`/en/self-hosting/configuration-generator/` is the forwarder page and the
`movedPages` row for that slug skips the default locale.

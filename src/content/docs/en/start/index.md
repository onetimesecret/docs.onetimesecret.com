Onetime Secret is a privacy-focused, ephemeral secret-sharing service: you put
something sensitive behind a link, the recipient opens it once, and it's gone.
This documentation covers creating, sharing and managing those self-destructing
messages — on the hosted service at
[onetimesecret.com](https://onetimesecret.com/), on an instance you run
yourself, or through the API.

## Core functionality

Onetime Secret provides a straightforward solution for sharing sensitive
information securely:

1. **One-time access** — view shared secrets once, then they're permanently
   deleted
2. **No registration required** — use basic features without an account
3. **Customizable expiration** — control secret availability with automatic
   deletion
4. **Optional passphrase** — add an extra security layer to shared secrets
5. **Open-source** — review our codebase for enhanced transparency

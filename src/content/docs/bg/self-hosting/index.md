Стартирайте собствена частна инстанция на Onetime Secret с пълен контрол върху вашите данни, сигурност и внедряване.

:::caution[Март 2026 — Документацията за самостоятелно хостване е в процес на преход]
В момента преминаваме от **v0.23** към **v0.24** (клонът `main`). Част от документацията ни за самостоятелно хостване е остаряла и [активно работим по нейното подобряване](https://github.com/onetimesecret/onetimesecret/issues/2628).

**Ако просто искате да стартирате нещо работещо**, препоръчваме клона `rel/0.23`. Той изисква само няколко променливи на средата и Redis, и все още активно добавяме поправки и малки актуализации към него.

```bash
git clone -b rel/0.23 https://github.com/onetimesecret/onetimesecret.git
```
:::

## Защо да хоствате сами?

Самостоятелното хостване на Onetime Secret ви дава:

- **Пълен контрол върху данните** - Всички тайни остават на вашата инфраструктура и мрежа
- **Персонализирани политики за сигурност** - Конфигурирайте удостоверяване, опции за поверителност и контрол на достъпа
- **Съответствие** - Изпълнявайте регулаторните изисквания за обработка на данни
- **Персонализиран бранд** - Персонализирайте интерфейса за вашата организация

## Бърз старт

Изберете метода на внедряване, който най-добре отговаря на вашата среда:

### Docker (Препоръчително)
```bash
# Стартиране на Redis и Onetime Secret
docker run -p 6379:6379 -d redis:bookworm
docker run -p 3000:3000 -d \
  -e REDIS_URL=redis://host.docker.internal:6379/0 \
  -e SECRET="$(openssl rand -hex 32)" \
  onetimesecret/onetimesecret:latest
```

Достъп на `http://localhost:3000`.

### Ръчна инсталация
За production среди, изискващи персонализирани конфигурации.

Вижте нашето ръководство за [Инсталиране и внедряване](./installation) за подробни стъпки.

## Какво е включено

Вашата самостоятелно хоствана инстанция включва:

- **Уеб интерфейс** - Пълнофункционален потребителски интерфейс за създаване и споделяне на тайни
- **REST API** - Програмен достъп за интеграции
- **Многоезична поддръжка** - Достъпна на 12+ езика
- **Персонализирани домейни** - Използвайте собствен домейн и бранд


## Системни изисквания

**Препоръчително:**
- 2+ CPU ядра
- 2GB+ RAM
- 10GB+ дисково пространство
- Redis за съхранение на сесии
- Node.js 22+ (за разработка)

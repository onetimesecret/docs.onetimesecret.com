---
title: 지역 변경하기
---

Onetime Secret은 다섯 개 지역(CA, EU, NZ, UK, US) 전체에서 [공유-무공유 아키텍처](/ko/regions)를 채택하고 있습니다. 각 지역은 자체 데이터베이스, 계정, 비밀 메시지를 갖춘 완전히 독립된 시스템으로 운영됩니다. 어떤 경우에도 지역 간에 데이터를 이전하지 않습니다.

즉, 지역을 변경하는 것은 "마이그레이션"이라기보다는 원하는 지역에서 새로 시작하는 것에 가깝습니다. 좋은 소식은 약 2분이면 충분하며, 구독은 자동으로 이어진다는 것입니다.

## 무료 계정

원하는 지역으로 직접 이동하여(전체 목록은 [사용 가능한 지역](/ko/regions#사용-가능한-지역) 참조) 동일한 이메일 주소로 새 계정을 만드세요. 이게 전부입니다 — 새 계정은 즉시 사용할 수 있습니다.

## 유료 계정(Identity Plus)

과정은 무료 계정과 동일하며, 한 단계만 추가됩니다:

1. 원하는 지역의 URL로 이동합니다(전체 목록은 [사용 가능한 지역](/ko/regions#사용-가능한-지역) 참조)
2. 구독에 연결된 것과 동일한 이메일 주소로 계정을 만듭니다
3. 로그인하여 계정 페이지로 이동합니다
4. 구독 상태가 Stripe를 통해 자동으로 인식됩니다

구독 정보가 동기화되려면 페이지를 한 번 새로 고쳐야 할 수도 있습니다. 이는 지역 간에는 데이터를 분리해서 관리하지만, 결제 관계는 Stripe를 통해 관리되고 Stripe가 지역 간에 이메일 주소를 인식하기 때문에 가능합니다.

## 기존 계정은 어떻게 되나요

이전 지역의 계정은 계속 정상적으로 작동합니다:

- 기존에 생성된 비밀 링크는 조회되거나 만료될 때까지 계속 작동합니다
- 참고할 사항이 있을 경우를 대비해 계정은 활성 상태로 유지됩니다
- 계정을 닫고 싶지 않다면 이전 계정에 대해 별도로 취할 조치는 없습니다

## 사용자 정의 도메인 이전

현재 지역에 사용자 정의 도메인을 설정해두었다면 조금 더 계획이 필요합니다. 기존 비밀 링크가 사용자 정의 도메인의 DNS 레코드를 사용하고 있기 때문에, 아직 조회되지 않은 링크가 깨지지 않도록 도메인을 곧바로 새 지역으로 돌릴 수는 없습니다.

### 단계별 안내

1. **임시 하위 도메인을 추가**하세요. 새 지역 계정에 임시 하위 도메인을 추가합니다. 예를 들어 현재 도메인이 `secrets.example.com`이라면 `secrets-new.example.com`이나 `secrets-us.example.com`과 같은 도메인을 추가합니다.

2. **임시 하위 도메인에 대한 CNAME 레코드를 생성**하여 해당 지역의 identity 엔드포인트를 가리키게 합니다(예: 미국 지역의 경우 `identity.us.onetime.co`). DNS 설정에 대한 자세한 내용은 [사용자 정의 도메인 설정 가이드](/ko/custom-domains/setup-guide)를 참조하세요.

3. **즉시 임시 하위 도메인 사용을 시작**하여 새 비밀 메시지를 생성합니다.

4. **30일이 지나면** 기존 도메인에서 생성된 비밀 메시지는 모두 만료된 상태가 됩니다. 이 시점에 다음을 진행할 수 있습니다:
   - 이전 지역 계정에서 사용자 정의 도메인을 제거합니다
   - 원하는 하위 도메인(예: `secrets.example.com`)을 새 지역 계정에 추가합니다
   - CNAME 레코드를 새 지역의 엔드포인트를 가리키도록 업데이트합니다
   - 계정 대시보드에서 도메인을 인증합니다

5. 원하는 도메인이 활성화되고 인증되면 **임시 하위 도메인을 정리**합니다.

### 왜 30일인가요?

비밀 메시지의 최대 유효 기간(TTL)은 30일입니다. 이 기간을 기다리면 이전 지역의 DNS 설정으로 생성된 모든 비밀 메시지가 조회되었거나 만료된 상태가 되므로, CNAME 레코드를 업데이트해도 남아 있는 링크가 깨지지 않습니다.

기존 비밀 메시지의 TTL이 더 짧거나 이미 모두 조회되었다는 사실을 알고 있다면 더 일찍 전환해도 됩니다.

## 사용자 정의 도메인이 없는 계정

사용자 정의 도메인을 사용하지 않는다면 전환은 즉시 이루어집니다. 이전 링크(`eu.onetimesecret.com/secret/abcd1234`와 같은 지역별 onetimesecret.com URL 사용)는 활성 계정이 어느 지역에 있든 관계없이 계속 정상적으로 연결됩니다.

## 여러 지역 사용

여러 지역에서 동시에 계정을 유지할 수 있습니다. 동일한 이메일 주소를 사용하는 모든 계정은 동일한 구독 상태를 공유합니다. 여러 지리적 지역의 사용자에게 서비스를 제공하며 지연 시간을 최소화하거나 데이터 상주 요건을 충족하고자 할 때 유용합니다.

## 전용 인스턴스

전용 인스턴스를 사용하는 고객은 지역 변경을 위해 [dedicated@onetimesecret.com](mailto:dedicated@onetimesecret.com)으로 문의해 주세요. 전용 인프라는 수동 재구성이 필요합니다. [피드백 페이지](https://onetimesecret.com/feedback)를 통해서도 문의하실 수 있습니다.

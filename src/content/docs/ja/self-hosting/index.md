## ま󠄁ず󠄁認󠄁証󠄁モ󠄁ー󠄁ド󠄁を󠄁選󠄁ぶ󠄁

認󠄁証󠄁モ󠄁ー󠄁ド󠄁に󠄁よ󠄁っ󠄁て󠄁、󠄁ほ󠄁か󠄁に󠄁何󠄁を󠄁稼󠄁働󠄁さ󠄁せ󠄁る󠄁必󠄁要󠄁が󠄁あ󠄁る󠄁か󠄁が󠄁決󠄁ま󠄁り󠄁ま󠄁す󠄁。󠄁イ󠄁ン󠄁ス󠄁ト󠄁ー󠄁ル󠄁前󠄁に󠄁決󠄁め󠄁て󠄁お󠄁い󠄁て󠄁く󠄁だ󠄁さ󠄁い󠄁。󠄁

`simple` は󠄁出󠄁荷󠄁時󠄁の󠄁デ󠄁フ󠄁ォ󠄁ル󠄁ト󠄁で󠄁、󠄁V󠄁a󠄁l󠄁k󠄁e󠄁y󠄁/󠄁R󠄁e󠄁d󠄁i󠄁s󠄁 データス󠄁トア󠄁だ󠄁け󠄁で動作します。`full` は󠄁アカウント用󠄁の󠄁 S󠄁Q󠄁L󠄁 デ󠄁ー󠄁タ󠄁ベ󠄁ー󠄁ス󠄁を󠄁追󠄁加󠄁します。デ󠄁フォ󠄁ルト󠄁は󠄁 `sqlite://data/auth.db` の󠄁 S󠄁Q󠄁L󠄁i󠄁t󠄁e󠄁 で󠄁、󠄁PostgreSQL は󠄁必󠄁須󠄁で󠄁は󠄁な󠄁く󠄁サ󠄁ポ󠄁ー󠄁ト󠄁対󠄁象󠄁の󠄁選󠄁択󠄁肢󠄁で󠄁す󠄁。󠄁コ󠄁ン󠄁テ󠄁ナ󠄁内󠄁で󠄁は󠄁、󠄁こ󠄁の󠄁フ󠄁ァ󠄁イ󠄁ル󠄁を再󠄁起󠄁動󠄁後󠄁も󠄁保󠄁持󠄁するた󠄁め󠄁に󠄁マ󠄁ウントし󠄁た󠄁ボ󠄁リ󠄁ュ󠄁ー󠄁ム󠄁が󠄁必󠄁要󠄁で󠄁す󠄁。󠄁

[S󠄁i󠄁m󠄁p󠄁l󠄁e󠄁 と󠄁 Fu󠄁l󠄁l󠄁 の󠄁比󠄁較󠄁](/en/self-hosting/simple-or-full-auth)で󠄁は󠄁、各󠄁モ󠄁ー󠄁ド󠄁で󠄁何󠄁が󠄁有󠄁効󠄁に󠄁な󠄁る󠄁か󠄁、󠄁そ󠄁の󠄁デ󠄁ー󠄁タ󠄁ベ󠄁ー󠄁ス󠄁をど󠄁こ󠄁に󠄁置󠄁く󠄁必󠄁要󠄁が󠄁あ󠄁る󠄁か󠄁、󠄁後󠄁か󠄁ら󠄁モ󠄁ー󠄁ド󠄁を󠄁切󠄁り󠄁替󠄁え󠄁る󠄁の󠄁が󠄁ど󠄁れ󠄁ほ󠄁ど󠄁難󠄁しい󠄁か󠄁を󠄁説󠄁明󠄁し󠄁て󠄁い󠄁ます。

## 運󠄁用󠄁者󠄁の󠄁み󠄁が󠄁行󠄁え󠄁る󠄁操󠄁作󠄁

管󠄁理󠄁作󠄁業󠄁の󠄁一󠄁部󠄁に󠄁は󠄁ア󠄁プ󠄁リ󠄁ケ󠄁ー󠄁シ󠄁ョ󠄁ン󠄁上󠄁の󠄁画󠄁面󠄁が󠄁な󠄁く󠄁、󠄁イ󠄁ン󠄁ス󠄁タ󠄁ン󠄁ス󠄁の󠄁コ󠄁マ󠄁ン󠄁ド󠄁ラ󠄁イ󠄁ン󠄁か󠄁ら󠄁実󠄁行󠄁し󠄁ま󠄁す󠄁。󠄁

主󠄁な󠄁も󠄁の󠄁は󠄁、󠄁組󠄁織󠄁を󠄁新󠄁し󠄁い󠄁オ󠄁ー󠄁ナ󠄁ー󠄁に󠄁移󠄁管󠄁す󠄁る󠄁操󠄁作󠄁で󠄁す󠄁。󠄁組󠄁織󠄁の󠄁オ󠄁ー󠄁ナ󠄁ー󠄁に󠄁は󠄁そ󠄁の󠄁た󠄁め󠄁の󠄁画󠄁面󠄁も󠄁エ󠄁ン󠄁ド󠄁ポ󠄁イ󠄁ン󠄁ト󠄁も󠄁な󠄁い󠄁た󠄁め󠄁、󠄁移󠄁管󠄁は󠄁運󠄁用󠄁者󠄁が󠄁行󠄁う󠄁必󠄁要󠄁が󠄁あ󠄁り󠄁ま󠄁す󠄁。󠄁以󠄁下󠄁の󠄁コ󠄁マ󠄁ン󠄁ド󠄁を󠄁使󠄁用󠄁し󠄁て󠄁く󠄁だ󠄁さ󠄁い󠄁。󠄁自󠄁動󠄁化󠄁す󠄁る󠄁場󠄁合󠄁は󠄁、󠄁C󠄁o󠄁l󠄁onel󠄁 A󠄁P󠄁I󠄁 が󠄁同󠄁じ󠄁操󠄁作󠄁を󠄁 `POST /api/colonel/organizations/:org_id/transfer-ownership` で󠄁公󠄁開󠄁し󠄁て󠄁い󠄁ま󠄁す󠄁。󠄁こ󠄁れ󠄁に󠄁は󠄁 c󠄁o󠄁l󠄁o󠄁n󠄁e󠄁l󠄁 ロ󠄁ー󠄁ル󠄁が󠄁必󠄁要󠄁で󠄁、󠄁確󠄁認󠄁と󠄁し󠄁て󠄁組󠄁織󠄁名󠄁を󠄁受󠄁け󠄁取󠄁り󠄁、󠄁プ󠄁レ󠄁ビ󠄁ュ󠄁ー󠄁な󠄁し󠄁で󠄁即󠄁時󠄁に󠄁適󠄁用󠄁さ󠄁れ󠄁ま󠄁す󠄁。󠄁

```bash
bin/ots org transfer-ownership ORG NEW_OWNER
```

`ORG` は󠄁組󠄁織󠄁の󠄁公󠄁開󠄁 I󠄁D󠄁（󠄁`extid`、󠄁C󠄁L󠄁I󠄁 が󠄁表󠄁示󠄁す󠄁る󠄁 I󠄁D󠄁）󠄁ま󠄁た󠄁は󠄁内󠄁部󠄁 I󠄁D󠄁（󠄁`objid`）󠄁で󠄁す󠄁。󠄁`NEW_OWNER` は󠄁メ󠄁ー󠄁ル󠄁ア󠄁ド󠄁レ󠄁ス󠄁、󠄁顧󠄁客󠄁 e󠄁x󠄁t󠄁i󠄁d󠄁、󠄁ま󠄁た󠄁は󠄁 R󠄁o󠄁d󠄁a󠄁u󠄁t󠄁h󠄁 ア󠄁カ󠄁ウ󠄁ン󠄁ト󠄁 I󠄁D󠄁 で󠄁、󠄁**す󠄁で󠄁に󠄁ア󠄁ク󠄁テ󠄁ィ󠄁ブ󠄁な󠄁メ󠄁ン󠄁バ󠄁ー󠄁で󠄁あ󠄁る󠄁必󠄁要󠄁が󠄁あ󠄁り󠄁ま󠄁す󠄁**。󠄁こ󠄁の󠄁コ󠄁マ󠄁ン󠄁ド󠄁は󠄁顧󠄁客󠄁を󠄁作󠄁成󠄁し󠄁な󠄁い󠄁た󠄁め󠄁、󠄁メ󠄁ン󠄁バ󠄁ー󠄁で󠄁な󠄁い󠄁場󠄁合󠄁は󠄁先󠄁に󠄁 `bin/ots memberships add ORG CUSTOMER` を󠄁実󠄁行󠄁し󠄁て󠄁く󠄁だ󠄁さ󠄁い󠄁。󠄁

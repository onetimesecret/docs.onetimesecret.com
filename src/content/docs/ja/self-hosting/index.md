## セルフホスティングの利点

Onetime Secretをセルフホスティングすると以下のメリットがあります：

- **完全なデータコントロール** - すべてのシークレットは自社のインフラストラクチャとネットワーク内に保持されます
- **カスタムセキュリティポリシー** - 認証、プライバシーオプション、アクセス制御を設定できます
- **コンプライアンス** - データ取り扱いに関する規制要件を満たします
- **カスタムブランディング** - 組織に合わせてインターフェースをカスタマイズできます

## クイックスタートオプション

お使いの環境に最適なデプロイメント方法をお選びください：

### Docker（推奨）
```bash
# RedisとOnetime Secretを起動
docker run -p 6379:6379 -d redis:bookworm
docker run -p 3000:3000 -d \
  -e REDIS_URL=redis://host.docker.internal:6379/0 \
  -e SECRET="$(openssl rand -hex 32)" \
  onetimesecret/onetimesecret:latest
```

`http://localhost:3000`でアクセスできます。

### 手動インストール
カスタム設定が必要なプロダクション環境向けです。

詳細な手順については、[インストールとデプロイメント](./installation)ガイドをご覧ください。

## 含まれる機能

セルフホスティングインスタンスには以下が含まれます：

- **Webインターフェース** - シークレットの作成と共有のためのフル機能UI
- **REST API** - インテグレーションのためのプログラマティックアクセス
- **多言語サポート** - 12以上の言語に対応
- **カスタムドメイン** - 独自のドメインとブランディングを使用可能

## システム要件

**推奨：**
- 2コア以上のCPU
- 2GB以上のRAM
- 10GB以上のディスク容量
- セッションストレージ用のRedis
- Node.js 22以上（開発用）
